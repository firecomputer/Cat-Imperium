# Cat Empire 개발 진행 보고서 및 로드맵

- 작성일: 2026-07-14
- 대상 브랜치: `master`
- 기준 마일스톤: 한·중·일 경제 수직 슬라이스
- 엔진: Godot 4.x (`project.godot` 기능 표기 4.6, 현재 검증 환경 4.4 stable)

## 1. 요약

현재 프로젝트는 9,900개 프로빈스로 구성된 전 세계 정치 지도를 기반으로, 대한민국을 플레이어 국가로 두고 중국과 일본의 경제 AI가 함께 동작하는 7일 단위 턴제 경제 게임까지 구현되었다.

플레이어는 소비재 비율, 품목별 민간공장 배정, 세율, 프로빈스별 건설을 조작할 수 있다. 턴 종료 시 생산, 한·중·일 무역, 소비, 가격, 생활수준, 세수, AI 결정, 건설 진행이 결정론적으로 처리된다. 게임 상태는 단일 JSON 슬롯에 저장하고 복원할 수 있다.

현 단계는 전체 대전략 게임 중 경제 기반을 완성한 첫 번째 플레이 가능한 마일스톤이다. 군수 생산, 복수 부대, 전선, 전투, 영토 점령, 외교는 다음 마일스톤에서 순차적으로 추가한다.

## 2. 현재 구현 상태

### 2.1 지도와 국가 기반

- 4096×2048 RGB 프로빈스 비트맵과 9,900개 프로빈스 메타데이터를 사용한다.
- 각 프로빈스는 국가, 면적, 기후, 인접 프로빈스, 해안 여부, 안전한 라벨 좌표를 가진다.
- WASD 카메라 이동, 커서 중심 휠 줌, 지도 경계 제한, 좌클릭 프로빈스 선택이 동작한다.
- 프로빈스의 `neighbors` 데이터는 이후 전선 연결요소 계산에 바로 사용할 수 있다.
- 현재 활성 국가는 대한민국, 중국, 일본이며 대한민국이 플레이어로 고정되어 있다.

### 2.2 경제 시뮬레이션

- 한 턴은 7일이며 날짜와 턴 번호가 함께 진행된다.
- 민간공장은 소비재 생산, 건설, 자동 무역으로 나뉜다.
- 소비재 공장 수는 `floor(전체 민간공장 × 소비재 비율)`을 기본으로 하되 진행 중 건설이 우선권을 가진다.
- 플레이어는 소비재 공장을 13개 민간 품목에 직접 배정한다.
  - 필수품: 사료, 의류, 가구, 도자기, 비누
  - 자원: 목재, 콘크리트, 철강, 유리
  - 사치품: 츄르, 장난감, 개다래나무, 고급 사료
- 품목별 생산량, 수요, 재고, 기준 가격, 최저·최고 가격, 무역 묶음 크기는 `data/economy_catalog.json`에서 관리한다.
- 가격은 목표 재고 대비 부족률을 기반으로 계산하고 매 턴 50%씩 목표 가격에 수렴한다.
- 필수품 충족률, 필수품 가격 접근성, 사치품 충족률, 세금 부담이 생활수준 0–10에 반영된다.
- 세율은 0–50% 범위에서 조절하며, 소비 가치와 생활수준을 바탕으로 주간 세수가 국고에 들어간다.
- 모든 재고, 가격, 국고는 음수 또는 비정상 수치가 되지 않도록 제한·검증한다.

### 2.3 무역과 비플레이어 AI

- 소비재와 건설에 사용되지 않은 민간공장은 자동 무역 공장이 된다.
- 세 국가의 거래 요청은 전역에서 우선순위를 계산한 후 일괄 정산하므로 국가 처리 순서가 결과를 바꾸지 않는다.
- 구매국은 목표 재고보다 부족한 품목 중 국내 잠정 가격이 높은 품목을 먼저 찾는다.
- 판매국은 목표 재고를 넘는 잉여 재고와 가장 낮은 가격을 제공해야 한다.
- 구매국은 판매 가격과 10% 운송비를 지불하고, 판매국은 판매 가격만큼 국고를 받는다.
- 중국과 일본 AI는 매 턴 필수품 부족과 가격 압력을 기준으로 생산 공장을 재배정한다.
- AI는 국고, 자재, 가용 무역 공장이 충분할 경우 국가당 한 건의 민간공장 건설을 진행한다.
- 경제 계산에는 난수를 사용하지 않으므로 같은 상태에서 같은 결과가 나온다.

### 2.4 건설

- 플레이어 소유 프로빈스당 하나의 건설 프로젝트만 동시에 진행할 수 있다.
- 민간공장, 군수공장, 조선소를 건설할 수 있다.
- 건설 시작 시 국고와 목재·콘크리트·철강·유리를 즉시 지불한다.
- 건설 기간은 100일이다. 7일 단위이므로 14턴 뒤 2일이 남고 15번째 턴에 완공된다.
- 조선소는 `water_border`가 참인 해안 프로빈스에만 지을 수 있다.
- 취소 시 점유 민간공장은 반환되지만 비용과 자재는 환불하지 않는다.
- 완공된 건물은 프로빈스 건물 수와 국가 공장 총계에 동시에 반영된다.
- 군수공장과 조선소는 현재 건설만 가능하며 생산 기능은 후속 마일스톤까지 비활성 상태다.

### 2.5 UI와 고양이 지도자

- 1280×720 PC 마우스·키보드 환경을 기준으로 구성되어 있다.
- 상단 바에서 날짜, 턴, 국고, 주간 세수, 생활수준, 민간공장 분배를 확인할 수 있다.
- 경제 탭에서 소비재 비율, 세율, 품목 가격·재고·수요·생산·무역·공장 배정을 조작한다.
- 건설 탭은 지도에서 선택한 프로빈스의 소유권, 해안 여부, 면적, 건물, 진행 중 프로젝트를 표시한다.
- 국가별 고양이 지도자 이름, 성향, 색상과 교체 가능한 임시 SVG 초상을 표시한다.
- 기존 지도 이동·줌·선택 기능을 유지하며 UI 위 입력은 지도 조작에 전달되지 않는다.

### 2.6 저장과 복원

- 기본 저장 위치는 `user://savegame.json`이며 단일 수동 슬롯을 사용한다.
- 턴, 날짜, 플레이어 국가, 국고, 세율, 생활수준, 공장, 품목별 재고·가격·배정, 프로빈스 건물, 건설 프로젝트를 저장한다.
- 임시 파일 작성 후 기존 저장을 백업하고 교체한다. 교체 실패 시 이전 저장을 복원한다.
- 불러오기 전에 스키마, 국가, 품목, 수치 범위, 생산 한도, 프로빈스 소유권, 건설 프로젝트를 검증한다.
- 손상되거나 지원하지 않는 저장 파일은 현재 게임 상태를 변경하지 않는다.

## 3. 코드 구조

- `scripts/game_state.gd`: 시나리오 초기화, 턴 오케스트레이션, 생산, 무역, 소비, 세수, AI, 건설, 저장 검증의 중심이다.
- `scripts/country.gd`: 국가 경제 상태, 공장 분배 계산, 주간 통계, 저장 직렬화를 담당한다.
- `scripts/item.gd`: 민간·군수·함선 품목과 민간 품목 분류 및 경제 파라미터를 정의한다.
- `scripts/economy_ui.gd`: 경제·건설 화면을 구성하고 공개 `GameState` 명령 API만 호출한다.
- `scripts/province_map_database.gd`: 프로빈스·국가·RGB 선택 데이터를 제공한다.
- `data/economy_catalog.json`: 품목과 한·중·일 초기 밸런스의 데이터 원본이다.
- `tools/verify_economy.gd`: 경제 마일스톤의 헤드리스 통합 검증이다.

지식 그래프 기준 현재 코드는 15개 파싱 대상 파일, 149개 노드, 약 1,900개 관계와 39개 실행 흐름으로 구성된다. 주요 런타임 흐름은 시나리오 초기화, `advance_turn`, `load_game`, `start_construction`, 경제 UI 이벤트다.

## 4. 검증 기준선

다음 명령이 현재 모두 성공한다.

```bash
godot4 --headless --path . --script res://tools/verify_game_foundation.gd
godot4 --headless --path . --script res://tools/verify_economy.gd
godot4 --headless --path . --script res://tools/verify_godot_map.gd
godot4 --headless --path . --quit-after 3
python3 -m json.tool data/economy_catalog.json
```

경제 검증은 다음 항목을 포함한다.

- 민간공장 10개, 소비재 40%, 건설 2개의 4/2/4 분배
- 비용·자재 지불, 중복 건설·외국 영토·AI 국가 직접 조작 거부
- 14턴/15턴 건설 경계와 공장 총계 갱신
- 가격 상·하한, 재고·국고 비음수, 생활수준 범위
- 세율 0%와 50%의 세수 및 생활수준 효과
- 저장 왕복 복원과 손상 파일 거부
- 중국·일본 AI를 포함한 100턴 안정성
- 경제 UI 정책 조작과 지도 선택 건설의 `GameState` 연결

## 5. 알려진 제한과 기술 부채

- 플레이어 국가는 대한민국으로 고정되어 있고 국가 선택 화면이 없다.
- 실제 세계 인구·GDP는 표시 데이터로 유지하지만 경제 수요는 플레이 밸런스를 위한 압축 지수를 사용한다.
- 자원은 현재 건설에만 소비되며 완제품 생산망의 투입재로 사용되지 않는다.
- 중국·일본 AI는 경제와 민간공장 건설만 수행하며 외교·군사 전략이 없다.
- 군수공장과 조선소는 생산선이 없으므로 완공 후 수량 지표로만 존재한다.
- UI는 1280×720 기준이며 4K, 초광폭, 모바일용 반응형 배치는 아직 없다.
- 현재 자동 검증은 독립 테스트 프레임워크가 아닌 `SceneTree` 기반 통합 스크립트다. 지식 그래프는 이를 테스트 노드로 자동 분류하지 못한다.
- `GameState`가 경제·건설·저장을 함께 맡고 있어 군사 기능을 넣기 전에 하위 서비스로 분리하는 것이 바람직하다.
- 지도 원본 재생성 자료는 약 200MB 이상이다. 초기 스냅샷에는 결정론적 지도 재생성을 위해 포함하지만, 원격 저장소 정책에 따라 Git LFS 또는 별도 데이터 배포를 검토해야 한다.

## 6. 앞으로의 진행 방향

### 마일스톤 2: 군수 생산과 보급

목표는 군수공장을 장비 생산선에 배정하고 생산된 장비가 국가 재고를 거쳐 부대에 보급되는 폐쇄 루프를 만드는 것이다.

1. 군사 품목 카탈로그를 추가한다.
   - 총, 무전기, 의료 장비, 보급 장비
   - 기갑 장비, 장갑 차량
   - 전투기, 근접지원항공기, 폭격기
2. 군수공장 생산선에 품목, 공장 수, 주간 생산량, 신뢰도를 둔다.
3. 국가 장비 재고와 부대별 보급 요청을 추가한다.
4. 보급 우선순위와 부족 장비 표시 UI를 구현한다.
5. 부대 장비 상한을 검증한다.
   - 보병·지원 장비 각각 `≤ 인력`
   - 기갑·장갑 차량 합계 `≤ 인력 × 0.5`
   - 항공기 합계 `≤ 인력 × 0.2`
6. 경제 턴과 군수 턴을 독립 서비스로 분리하고 `GameState.advance_turn()`이 순서만 조정하도록 리팩터링한다.

완료 기준은 플레이어가 군수공장을 특정 장비에 배정하고, 여러 턴 뒤 국가 재고가 증가하며, 선택한 부대에 장비를 이전하고 상한 초과가 차단되는 것이다.

### 마일스톤 3: 복수 부대와 자동 전선

1. 국가가 단일 `army` 대신 여러 `Army` 리소스를 소유하도록 마이그레이션한다.
2. 부대 필드에 ID, 표시 이름, 소유국, 인력, 장비 목록, 소속 전선 ID를 둔다.
3. 전쟁 상대와 맞닿은 프로빈스를 `neighbors` 그래프로 수집한다.
4. 같은 적국과 이어진 국경 프로빈스를 연결요소로 나누어 `전선 1`, `전선 2`처럼 자동 생성한다.
5. 영토 변경이나 전쟁 상태 변경 후 전선을 재계산하고 기존 부대를 가능한 전선에 유지한다.
6. 전선 라벨 좌표는 국경 프로빈스들의 안전 좌표와 화면 겹침 회피를 이용해 계산한다.
7. 플레이어 국가의 전 전선과 전쟁 중인 적국 전선에만 병력을 `100k`, `1m` 형식으로 크게 표시한다.

완료 기준은 하나의 국경이 지형적으로 분리될 때 별도 전선으로 생성되고, 전선에 배정된 부대 인력 합계가 지도 위에 읽기 좋게 표시되는 것이다.

### 마일스톤 4: 전쟁, 전투, 영토 점령

1. 전쟁과 참전국 데이터 모델을 추가한다.
2. 선전포고 후 첫 턴은 준비 턴으로 두고 다음 턴부터 전투를 계산한다.
3. 전선별 아군·적군 인력, 장비 충족률, 항공 전력, 보급 상태를 전투력으로 환산한다.
4. 승리 측은 전선 앞쪽의 적 프로빈스를 점령하며 전력 우위가 클수록 한 턴에 더 많이 점령한다.
5. 점령 후보는 현재 전선에 직접 접한 적 프로빈스로 제한해 영토가 순간이동하지 않게 한다.
6. 점령 후 소유권, 전선, 건물 접근권, 경제 생산 기여도를 갱신한다.
7. 결정론적 전투 로그와 지도 점령 색상 갱신을 구현한다.

완료 기준은 선전포고, 한 턴 대기, 전투, 프로빈스 점령, 전선 재계산이 반복 가능한 하나의 전쟁 루프를 형성하는 것이다.

### 마일스톤 5: 외교

1. 국가 관계와 외교 상태를 데이터화한다.
2. 전쟁, 종전, 동맹, 불가침조약, 통행권 명령을 구현한다.
3. 각 조약의 중복·충돌·해지 조건과 AI 수락 점수를 정의한다.
4. 동맹·통행권이 전선, 부대 이동, 전쟁 참전에 미치는 영향을 연결한다.
5. 전쟁 점수와 점령 상태를 이용한 기본 종전 협상을 추가한다.
